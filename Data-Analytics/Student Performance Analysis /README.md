
# Student Performance Analysis

## Project Overview

This project demonstrates the use of Microsoft Excel
to analyse student academic performance.

The analysis focuses on identifying academic trends,
calculating performance indicators, and presenting
results through an interactive Excel dashboard.

## Business Problem

Educational institutions need accurate information
to monitor student performance and identify areas
where additional academic support may be required.

This project explores how student assessment data
can be transformed into meaningful insights.

## Project Objectives

1. Calculate average student marks.
2. Determine pass and fail rates.
3. Identify the highest and lowest marks.
4. Identify the top three performing students.
5. Compare performance across subjects.
6. Develop an Excel dashboard.

## Tools and Technologies

- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Data Cleaning
- Data Visualisation

## Methodology

### 1. Data Collection
Created a fictional student performance dataset.

### 2. Data Cleaning
Checked for missing values, duplicate records
and invalid marks.

### 3. Data Analysis
Used Excel formulas and PivotTables to calculate
academic performance indicators.

### 4. Data Visualisation
Created charts to present subject averages,
student performance and pass rates.

### 5. Reporting
Documented findings and recommendations.
